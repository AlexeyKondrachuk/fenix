# Феникс

Инструкция по [деплою на VPS и переносу базы и медиа](deploy/README.md).

Сайт центра психологии. Next.js App Router, SCSS Modules, Prisma и PostgreSQL.

## Локальный запуск

1. Скопируйте `.env.example` в `.env`. Задайте пароль PostgreSQL в обоих полях, используя URL-кодирование в `DATABASE_URL`, если нужно. Задайте отдельные случайные значения для `ADMIN_PASSWORD` и `ADMIN_SESSION_SECRET`.
2. Выполните `npm ci`.
3. Запустите `docker compose up -d --wait`.
4. Выполните `node scripts/export-review-media.cjs`, затем `npx prisma migrate deploy`. При обновлении старой установки остановите приложение перед экспортом. Скрипт переносит прежние вложения отзывов в файловое хранилище и проверяет копии.
5. Выполните `npm run dev`. Сайт откроется на http://localhost:3100, админка — на http://localhost:3100/admin.

Пароль для локальной админки хранится в `.env` в поле `ADMIN_PASSWORD`.

## Резервная копия

В обзоре админки кнопка «Скачать базу данных» выгружает базу PostgreSQL в файл `.dump`, а «Скачать фото и видео» — архив материалов `.tar.gz`. Скачайте оба файла. Выберите флешку или внешний диск в диалоге сохранения браузера. Если браузер автоматически использует «Загрузки», включите запрос места сохранения.

По умолчанию используется `pg_dump` внутри сервиса `postgres` из Docker Compose. Для сервера с отдельной базой установите PostgreSQL client совместимой версии, задайте `DATABASE_BACKUP_MODE=pg_dump` и при необходимости `PG_DUMP_PATH` (путь к исполняемому файлу). Подключение берётся из `DATABASE_URL`. Лимит выгрузки — 256 МБ и 120 секунд; хостинг должен разрешать запуск процессов.

Файл `.dump` содержит структуру и данные базы, включая статьи и контакты. Восстановление выполняется утилитой `pg_restore` в подготовленную базу, желательно сначала на отдельной тестовой базе. Формат описан в [документации PostgreSQL](https://www.postgresql.org/docs/16/app-pgdump.html).

Архив фото и видео содержит все файлы из `article-uploads` (или `ARTICLE_UPLOAD_DIR`) с сохранением относительных путей. Для восстановления распакуйте его содержимое в эту папку. Архив создаётся библиотекой Node.js без внешней утилиты `tar`. На сервере требуется свободное место во временной папке для архива и возможность выполнять запрос до 11 минут. Временный архив удаляется после передачи или прерывания скачивания. Не редактируйте статьи и не загружайте материалы во время создания пары копий: база и файлы выгружаются отдельно. Видеоархивы большого размера требуют соответствующего объёма памяти в браузере при скачивании.
